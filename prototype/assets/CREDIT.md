# Sprite credit

`oneko.gif` is the classic "Neko" desktop-pet cat sprite (originally by
Masayuki "Kenji" Kimura, 1989 — see https://en.wikipedia.org/wiki/Neko_(software)),
via this specific redraw/distribution:

- Source: https://github.com/adryd325/oneko.js (`oneko.gif`, unmodified)
- License stated in that repository: MIT, Copyright © 2022 adryd
- This exact sprite is already reused as-is by many other MIT-licensed
  projects (Vencord's oneko plugin, the Spicetify oneko fork, an
  OpenUserJS userscript, etc.) — see that repo's README for links.

Used here purely as a **placeholder for the prototype**, to prove the
desktop-pet mechanics (movement, click-through, app open/close) with
sprite art that actually reads as a cat, instead of continuing to
hand-draw one in code. The real product (see `docs/` at the repo root)
plans to use live 3D CC0 Quaternius models per the master plan, not this
sprite — swap this out before anything resembling a public release.
